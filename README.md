## Overview

Module Inserter adds a blueprint-like tool for configuring and deploying modules into machines across an entire Factorio factory. Define a module loadout for each machine type and the mod dispatches construction bots to fill every matching machine with the configured modules in one operation, saving hours of manual module insertion.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Factorio Module Inserter** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Bulk Module Deploy** | Configure module loadouts and bots fill all matching machines at once |
| **Per-Machine Config** | Different module configurations for assemblers, labs, and miners |
| **Bot Dispatching** | Uses construction bots for module insertion without player involvement |
| **Blueprint Compat** | Module configurations saved alongside entity blueprints |
